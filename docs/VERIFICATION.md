# 검증 기록

검증일: 2026-09-30

## 원본 확인

게임24 퍼즐마작2의 게임 도움말, 실제 시작 화면, 실행 파일의 규칙 상수를 확인했습니다. 시작 시 4분, 120장, 힌트 3회가 표시됩니다. 안내의 ‘3번 이하로 꺾임’은 실제 판정과 도움말의 도형에서 **직선 3개 / 꺾임 2회**에 해당합니다. 구현은 실제 판정에 맞췄습니다. 원본 소스나 자산을 배포하지 않습니다.

## 자동 검증

- 7개 게임 엔진 테스트 통과.
- 독립적인 방향 탐색 알고리즘과 1,800개 연결 사례 대조: 일치.
- 외곽 연결, 가로·세로 연결, 1~2회 꺾기, 막힌 경로, 자기 자신 선택 확인.
- 120장과 6단계별 시간·그림 수·짝수 분포 확인.
- 200점, 2초 추가, 10초 차감, 3회 힌트 및 단계 간 잔여 힌트 유지 확인.
- 6단계 보너스와 최종 완료, 시간 초과, 막힘 종료, 잘못된 상태 전환 확인.
- 동일 플레이 기록을 재생하여 결과·점수가 일치하는지 확인.
- 개발 서버 및 빌드된 Worker 모두에서 API 통합 테스트 2개 통과.
- 저장 후 조회, 동시 저장의 중복 방지, 임의 점수 무시, 잘못된 이름·토큰·시간·플레이 기록 거절 확인.
- TypeScript 검사 및 프로덕션 빌드 통과.

## 실제 화면 검증

- 실제 타일 두 장 클릭: 점수 200, 잔여 타일 118로 변경.
- 힌트: 점수 400, 잔여 힌트 2회로 변경.
- 일시정지 사이 타이머 표시 불변 확인.
- 1단계 및 2단계 클리어와 다음 단계 진입 확인.
- 3단계에서 더 연결할 짝이 없어 정상 종료.
- 결과 화면의 **40,770점**을 이름과 함께 저장.
- 기록실에 같은 점수가 표시되고 새로고침 후에도 유지됨을 확인.
- 전체화면 진입·복귀 버튼 동작 확인.
- 기본 1280×720, 1920×1080, 390×844 크기 확인. 가로 넘침 없음, PC 세로 넘침 없음, 작은 화면 대화상자 범위 정상.
- 브라우저 오류 로그 없음.
- WebMCP 읽기·새 게임·짝 선택 호출과 잘못된 인덱스 및 중복 시작 거절 확인.

화면 검증 기록은 로컬 테스트 DB에서만 생성했습니다. 운영 배포에 테스트 DB는 포함하지 않습니다. 브라우저 조작과 자동 검증은 무오류를 보증하는 것은 아니지만, 확인한 주요 플레이 및 점수 저장 경로에서 결함이 발견되지 않았습니다.

## 운영 배포 수정

초기 배포는 로컬 및 CI에서는 정상 동작했지만, 운영 배포 압축 파일에서 마이그레이션 경로가 잘못되어 DB에 테이블이 생성되지 않았습니다. 이 때문에 실제 주소의 게임 시작 및 기록 조회가 503으로 실패했습니다. 운영 DB의 빈 테이블 목록과 시작 요청 오류 로그로 확인했습니다.

배포 압축 파일은 `dist/.openai/drizzle/` 경로에 SQL과 마이그레이션 메타데이터를 포함해야 합니다. 공식 패키징 절차로 수정하고 `scripts/verify-deployment-archive.mjs`로 실제 배포 압축 파일의 경로를 확인하도록 보강했습니다. 런타임에서 테이블을 생성하거나 기존 데이터를 초기화하지 않습니다.
